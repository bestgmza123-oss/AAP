## Cross-system invariants for all tests

1. Server authority: do not trust client IDs/results; query and reuse stored receipts after timeout; a retry cannot repeat a mutation (AC-SYS01-03, AC-SYS33-01/02).
2. Custody/death: every quantity has one owner/location/lock and one terminal disposition; reconcile due events before later commands; no resurrection or successor credit (AC-SYS02-01..05, AC-SYS13-03, AC-SYS33-03/04).
3. Time: UTC is canonical; order due events by logical time, domain priority, stable sequence and event ID; worker arrival, retries, client timezone and DST cannot alter outcome (AC-SYS30-01/02, AC-SYS33-04).
4. Run/Combat/Loot: one persisted 4–7 enemy roll, one entry debit, one 30-minute timer, no Run-time regeneration backfill, server-resolved actions, no side effects from invalid commands, one optional return encounter and no duplicate rewards (AC-SYS09-01..05, AC-SYS07-01..05, AC-SYS10-01..05).
5. Content/scope: only validated immutable published rows influence active behavior; future-phase content and paid flows remain disabled; balance values are not proven by fixture arithmetic (AC-SYS32-01..05, AC-SYS31-01..04, balance/01_BALANCE_POLICY.md).
