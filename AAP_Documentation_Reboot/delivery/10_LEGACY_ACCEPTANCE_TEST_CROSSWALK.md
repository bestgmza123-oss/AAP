## Phase-gate completion rule

No Phase can be marked `Accepted` until all test rows allocated to that Phase have an explicit disposition, every required current criterion has an exact mapping, failures have been repaired or formally accepted as scoped residuals, and inspectable evidence exists. Tests shared across phases may be re-run in later phases; the task matrix identifies the first implementation home and does not waive later regression.
