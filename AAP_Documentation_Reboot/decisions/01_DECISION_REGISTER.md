## Owner-confirmed decisions (limited scope)

Owner-confirmed legacy choices are referenced in the owning files where material, including: three death causes; one active Character per Account; HP does not self-heal at Run end; no Stamina/Mana regeneration during a dungeon Run; carried capacity includes the bag but excludes worn gear; Country → Province → District; and real-time offline rules. Confirmation applies only to its stated scope; it does not prove implementation or runtime behavior.
